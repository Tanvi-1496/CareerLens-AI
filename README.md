<p align="center">
  <b>An AI-powered career guidance and placement readiness analysis platform</b>
</p>

---

## 📌 Overview

**CareerLens AI** is an intelligent career assistance system designed to help students analyze their career readiness, identify skill gaps, explore suitable career paths, and receive personalized recommendations.

The platform evaluates a student's academic profile, technical skills, projects, certifications, and career interests to generate meaningful insights related to placement preparation and professional growth.

CareerLens AI acts as a personal career co-pilot by combining intelligent scoring, recommendation algorithms, analytics, and an interactive dashboard experience.

---

# 🎯 Problem Statement

Students often face challenges such as:

- Difficulty understanding their placement readiness
- Lack of awareness about required industry skills
- Uncertainty while choosing career roles
- No personalized roadmap for improvement
- Difficulty analyzing their strengths and weaknesses

CareerLens AI addresses these challenges by providing:

✅ Career readiness analysis  
✅ Skill gap identification  
✅ Role recommendations  
✅ Personalized improvement roadmap  
✅ Resume-based profile insights

# ✨ Features

## 📊 Placement Readiness Analysis

- Calculates overall career readiness score
- Estimates placement probability
- Evaluates academic performance
- Analyzes technical skills and project experience
- Provides improvement suggestions


## 🧠 Skill Gap Analysis

- Compares current skills with target career roles
- Identifies missing technical skills
- Highlights areas requiring improvement
- Suggests learning paths


## 🎯 Career Recommendation Engine

- Suggests suitable career domains
- Provides role-based recommendations
- Generates personalized career roadmaps
- Helps students plan their learning journey


## 📄 Resume Intelligence

- Upload resume in PDF format
- Extract technical skills from resumes
- Analyze candidate profile information
- Provide profile improvement insights


## 💼 Company & Role Analysis

- Evaluates role suitability
- Provides eligibility insights
- Analyzes career opportunities based on profile


## 📈 Interactive Dashboard

Built using Streamlit with:

- User-friendly interface
- Data visualization
- Career analytics
- Progress tracking
- Interactive recommendations


## 📑 Career Report Generation

- Generates personalized PDF career reports
- Provides summarized profile analysis
- Helps students track improvement areas

# ⚙️ Installation & Setup

## 1. Clone Repository

```bash
git clone https://github.com/Tanvi-1496/CareerLens-AI.git
```

---

## 2. Navigate to Project Directory

```bash
cd CareerLens-AI
```

---

## 3. Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 4. Run Application

```bash
streamlit run placement_analyzer.py
```

The application will open in your browser.
